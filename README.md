# Modern Pricing UI

A clean, responsive pricing card interface built with HTML, Vanilla JavaScript, and Tailwind CSS.

## Features

- **Minimalist Design**: Clean typography and whitespace usage.
- **Responsive Layout**: Adapts from single column on mobile to three columns on desktop.
- **Interactive Toggle**: Switch between Monthly and Yearly pricing with smooth transitions.
- **Visual Hierarchy**: Highlighted "Pro" plan to guide user choice.
- **Zero Build Step**: Runs directly in the browser via CDN.

## Development

Since this project uses Tailwind CSS via CDN for simplicity in this prototype, you can simply open `index.html` in your browser.

For a local development server (optional):

```bash
npx serve .
```

## Customization

- Edit `index.html` to change text, features, or colors.
- Modify `script.js` to adjust pricing logic.
